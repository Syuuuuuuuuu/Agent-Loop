# AI 课程咨询顾问 —— 需求清单

> 课程演示项目。两个技术点:**Agent Loop(多工具自主决策)** + **教学自进化闭环(答不上 → 转人工 → 老师补充套路 → 下次答对)**。
> 定位:麻雀虽小五脏俱全的**企业级可落地架构**,但大模型与数据用**可替换的桩**,方便课程现场离线演示。

## 一、项目定位与技术选型

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 后端 | Python + FastAPI | Agent 生态成熟,演示代码清晰 |
| 大模型 | `LLMProvider` 抽象 + **Mock 实现** | 默认离线规则桩,可一行切换真实模型(OpenAI 兼容/国产/本地) |
| 向量库 | 本地实现(字符 n-gram / 特征哈希 + 余弦),SQLite 持久化 | 零外部依赖、离线可跑;可替换为 Chroma/pgvector / 模型 embedding |
| 存储 | SQLite | 零部署压力 |
| 前端 | 原生 HTML/CSS/JS 单页 | 聊天页(轨迹可视化)+ 后台(工单 + 套路库),无需切命令行 |
| 场景 | AI 课程咨询 | mock 课程目录 / 学员案例;销售套路由老师"教"出来 |

## 二、核心场景

AI 课程咨询:客户在聊天窗口咨询课程价格、周期、适合人群、就业前景等;Agent 先召回老师教过的"套路"(示范问答),再自主调用课程检索 / 学员案例等工具作答;遇到没教过、没把握的问题自动转人工生成工单,老师在后台补充标准答案后直接进套路库,系统下次即可自动答对。

## 三、两个技术点

### 技术点 ① Agent Loop(多工具自主决策)
- 核心循环:`推理 → 选工具 → 调用 → 观察结果 → 再决策 → 终止`
- 工具集:套路召回(recall_playbook)、课程检索(course_search)、学员案例(student_cases)、转人工(handoff)
- 循环边界控制:最大步数、超时、防死循环(企业落地要点)
- 全程记录 Agent 轨迹(每步思考 / 工具 / 入参 / 出参),前端可视化

### 技术点 ② 教学自进化闭环
- **教学模式**:老师教"示范问答"(客户问题 + 标准答案 + 这么答的原因),存入套路库
- **套路总纲**:AI 从全部示范中归纳通用应答策略;老师可手动改写,重新归纳时保留老师版本(状态合并)
- **触发**:没学过、没把握的问题 → Agent 主动转人工生成工单;或用户明确要求转人工
- **工单教学**:后台针对工单填答案 + 套路 → 直接进套路库并关闭工单
- **实测纠偏**:对话里随时对某条 AI 回复提意见 → AI 当场重答 → 可一键固化为套路
- **进化体现**:同一问题"补充前转人工 / 补充后直接答对";并提供套路库条目数、转人工率、命中率等统计佐证

## 四、功能模块

1. **Agent Loop 引擎**:循环、工具注册、边界控制、轨迹记录
2. **对话与展示界面**:聊天窗口 + 可视化思考过程 + 教学模式开关 + 纠偏操作
3. **教学自进化闭环**:套路库(增删改查 + top-k 语义召回)、总纲归纳、工单教学、实测纠偏
4. **业务设定**:全局人设 / 语气 / 铁律(后台可编辑,注入系统提示词)
5. **数据与桩**:mock 课程目录 / 学员案例、LLM 抽象与 Mock、embedding 抽象与本地实现
6. **演示支撑**:同一问题回放对比 + 统计看板

## 五、本期不做(后续可扩展)

- 多轮复杂对话记忆 / 用户画像
- 真实支付、下单
- 多租户、权限体系
- 失败案例驱动的 prompt 自动优化(作为"进阶展望"口头讲)
- 向量库替换 Chroma/pgvector、会话存储替换 Redis

## 六、需求决策记录(演进过程)

- 技术栈:Python + FastAPI
- 大模型:Mock 抽象层(可切换),已接入豆包(火山引擎 ARK)真实实现
- 界面:网页聊天页 + 可视化思考 + 后台 tab(工单 + 套路库管理)
- 数据:mock 课程目录 / 学员案例 + 本地向量套路库
- 侧重:两个技术点均衡,串成一个闭环故事
- 工具集:套路召回、课程检索、学员案例、转人工
- 转人工触发:Agent 低置信度自评 + 用户主动要求
- 知识入库:老师填答 → 直接入库(v1 曾有审核队列,现流程简化为"教学即入库")
- 进化展示:同一问题回放对比(并附统计看板)
- 存储:SQLite + 本地向量库
