# AI 课程咨询顾问 —— 演示用例(教学自进化)

> 现场照着这个脚本操作即可。每个用例标注了:操作、预期 Agent 行为(工具调用)、预期结果。
> 演示主线:**教学模式(老师教套路)** → **Agent Loop 多工具自主决策** → **自进化闭环(没教过 → 转人工 → 补充 → 下次答对)**。
> 自动化版本见仓库根目录 `_smoke_test.py`(跑一遍即验证全部用例)。

---

## 前置:从零开始(可选)

想演示"自进化"的完整过程,先清空数据:关闭服务 → 删除项目根目录的 `data.db` → 重新 `python run.py`(下次启动自动重建空库)。

---

## 第一幕:教学模式 —— 老师教三条套路

在聊天页打开右上角「教学模式」开关,依次教三条(问题 + 标准答案 + 这么答的原因):

| 客户问题 | 标准答案 | 这么答的原因(套路) |
| --- | --- | --- |
| 这个课多少钱? | 价格这块我想先了解一下你的学习目标和预算,再帮你看看哪个课程更合适。 | 先挖需求,不直接报价 |
| 太贵了,能便宜点吗? | 课程价值主要看能不能帮你真正转型,优惠方面可以跟班主任一对一沟通。 | 先塑造价值,不自己谈价,引导对接班主任 |
| 学完能找到工作吗? | 很多学员通过学习完成了转型,您可以看看真实的学员案例。 | 用真实案例给客户信心 |

> 看点:这不是写代码,是**用对话把销售套路教给 AI** —— 教学即配置。

---

## 第二幕:Agent Loop —— 自主选工具 + 按套路答

切回「客户视角」,依次问:

**用例 2.1 询价**
- 输入:`这个课多少钱?`
- 预期轨迹:`recall_playbook`(召回套路)→ `course_search`(查课程客观信息)→ 按"先挖需求"的套路回复
- 看点:Agent **自己决定**先召回套路、再检索课程,没有写死流程;回答遵守了你教的"不直接报价"。

**用例 2.2 就业咨询**
- 输入:`学完能找到工作吗?`
- 预期轨迹:`recall_playbook` → `student_cases`(检索学员案例)→ 用真实案例作答
- 预期结果:回复里出现具体学员案例(如"张同学(北京)……")。
- 看点:不同问题,Agent 选择了**不同的工具组合**。

---

## 第三幕:教学自进化闭环(核心)★

**用例 3.1 没教过的问题 → 自动转人工**
- 输入:`扫地机器人 X1 能翻越多高的门槛?`(明显超出课程咨询范围,且没教过)
- 预期轨迹:`recall_playbook`(召回相似度过低)→ Agent 自评没把握 → `handoff` 转人工
- 预期结果:回复"这个问题我还没学过,已为您转接人工客服处理",并生成工单。
- 后台:「后台(工单 + 套路库)」tab 出现该工单。

**用例 3.2 后台补充答案,教会它**
- 操作:在该工单下填写标准答案 `扫地机器人 X1 可自动翻越最高约 2cm 的门槛。`,可填套路原因,点「教会它并入库」
- 结果:工单关闭,套路库 +1 条。

**用例 3.3 回放验证(自纠错生效)★**
- 输入(再次):`扫地机器人 X1 能翻越多高的门槛?`
- 预期轨迹:`recall_playbook` 命中刚入库的样本 → 直接回答
- 预期结果:直接答出 `2cm`。
- 看点:**同一个问题,补充前转人工 / 补充后秒答** —— 最直观的自进化证据。

---

## 第四幕:实测纠偏 + 固化

**用例 4.1 对某条回复提意见**
- 操作:在第二条 AI 回复下方点「✍️ 纠偏」,输入意见,如:`别急着反问预算,先问候一句并表明愿意帮忙`
- 结果:AI 当场按意见重答这条回复(不写库,仅当场修正)。

**用例 4.2 固化为套路**
- 操作:对修正后的回复点「✅ 固化为套路」
- 结果:自动存为一条新套路样本,并**合并进套路总纲**(保留老师已改写的部分)。

> 注:纠偏重答依赖真实模型的语义能力;Mock 桩下会退化为原回复回显,属预期行为。

---

## 第五幕:统计看板(量化进化)

- 打开顶部指标看板,观察:
  - 套路库条目数:3 条(第一幕)→ 4 条(第三幕补充)→ 5 条(第四幕固化),**知识在增长**
  - 转人工率:随套路补充逐步下降,**系统在自我改善**
- 看点:不仅"看得见"个案,还能用**指标量化**系统进化。

## 演示动线建议(5 分钟版)

1. 第一幕 —— 教学模式,教 3 条套路(展示"教学即配置")
2. 第二幕 —— 秀 Agent 自主选工具 + 按套路答
3. 第三幕 —— 没教过 → 转人工(高潮前奏)
4. 切后台:3.2 补答案 → 3.3 回放,同一问题秒答(高潮)
5. 第五幕 —— 看板展示转人工率下降,收尾"系统会自进化"
