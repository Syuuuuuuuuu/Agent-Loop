## 数据模型(SQLite 表)

- `tickets`:转人工工单(id, question, context, status, created_at)
- `playbook`:套路库教学样本(id, question, answer, note, source, vector, vec_model, created_at)
- `settings`:键值设定(业务铁律 / 套路总纲)
- `metrics_log`:每次会话埋点(id, session_id, question, hit_kb, handoff, created_at)
- (保留兼容)`kb_audit` / `knowledge`:v1 电商版遗留表,当前流程不再使用

## 接口清单(当前实际)

- `POST /api/chat` 发消息,返回最终回复 + Agent 轨迹
- `POST /api/session/reset` 重置会话上下文
- `POST /api/teach` 教学模式:教一条套路(问题 + 标准答案 + 原因)
- `GET  /api/playbook` 套路库列表;`PUT/DELETE /api/playbook/{id}` 修改/删除
- `GET  /api/playbook/summary` 套路总纲(首次自动归纳)
- `PUT  /api/playbook/summary` 老师手动改写总纲
- `POST /api/playbook/summary/regenerate` 状态合并重新归纳
- `GET  /api/tickets` 工单列表
- `POST /api/tickets/{id}/teach` 针对工单补充答案 → 直接进套路库并关闭工单
- `POST /api/refine` 对话内纠偏(老师提意见,AI 当场重答)
- `POST /api/refine/commit` 把纠偏结果固化为套路样本
- `GET/PUT /api/settings/directive` 全局业务设定(人设/语气/铁律)
- `GET  /api/settings/system-prompt` 查看完整生效的系统提示词
- `GET  /api/metrics` 统计看板(套路库条目数、转人工率、命中率)

## 验收标准

1. 启动后浏览器打开聊天页,教学模式下教几条套路,再切客户视角提问 → Agent 自主选工具回答(轨迹可见)。
2. 问没教过且没把握的问题 → 自动转人工生成工单。
3. 后台针对工单补充答案 → 直接入库,工单关闭。
4. 重新问同一问题 → 直接答对(不再转人工)。
5. 统计看板能看到入库前后转人工率变化。
